## قيود وقرارات معلّقة (صريحة)
- **الفواتير داخلية وليست ضريبية** (قرار D7 لم يُحسم). أي ربط بمصلحة الضرائب خارج النطاق.
- **البحث بالصورة** ببصمة إدراكية: يجد التصميم المطابق/القريب جدًا، ولا يفهم المحتوى دلاليًا؛ ملفات PDF لا تُفهرس (D6).
- **المطابقة البكسلية للـpen**: أُجري توحيد التخطيط (شريط جانبي/علوي موحّد، تبويبات موحّدة، جوال، تعريب) بطلب المالك، فبعض الشاشات تختلف عن لقطات الـpen عمدًا (انظر `11-ui-deviations.md`). `run-all.mjs` يعطي لوحة نتائج.
- شاشات الجوال المخصّصة M-A*/M-B*: مُنفّذة كتخطيط متجاوب (وبطاقة نظرة عامة مخصّصة لرابط الأوردر) وليست مطابقة بكسل لكل إطار.
- WhatsApp (D3)، حدود الملفات (D2)، الاحتفاظ/النسخ (D5)، الاستضافة (D8): قيم افتراضية معقولة، وتُضبط من الإعدادات/البيئة.
- استعادة النسخة الاحتياطية: السكربت موجود ومُجرَّب للنسخ؛ **جرّب الاسترجاع على بيئة منفصلة قبل الاعتماد عليه**.

## أوامر التحقق
```bash
docker compose run --rm -e DB_DATABASE=pbms_test_me app php artisan test         # Pest (استخدم قاعدة مستقلة إن كان غيرك يشغّل الاختبارات)
docker compose run --rm app vendor/bin/phpstan analyse --memory-limit=1G
npx tsc --noEmit && npx eslint resources/js --max-warnings=0 && npm test && npm run build
./tools/ui-compare/e2e-all.sh                                                   # 62 رحلة أزرار على قاعدة معزولة
node tools/ui-compare/click-audit.mjs --as <email> <مسارات>                      # كشف الأزرار الميتة
node tools/ui-compare/latin-scan.mjs --as <email> <مسارات>                       # كشف نص غير معرّب
```
النشر: `docs/13-deployment.md`.
