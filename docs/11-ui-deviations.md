# 11 — سجل الفروق المقصودة عن تصميم pen
المبدأ: لا فرق إلا إذا كان **خطأ نسخ واضحًا في التصميم** أو **ملاحظة تصميم لا تخص المستخدم** أو **تفرضه قاعدة عمل (BR-*)**. كل فرق يُسجَّل هنا مع السبب، ويُعدَّل التصميم لاحقًا إن رغب المالك.

| الشاشة | الفرق | السبب |
|---|---|---|
| S-066 (إضافة/تعديل موظف) | تسمية الحقلين الأولين «البريد الإلكتروني *» و«الاسم الكامل *» بدل «اسم العميل» المكتوبة في كلا الحقلين | خطأ نسخ واضح في التصميم (اسم الطبقة = البريد/الاسم) |
| S-065 (قائمة الموظفين) | حذف الملاحظة «الحالة والتوفر والتواريخ والبريد غير متاحة في البيانات المحفوظة؛ لم تُختلق…» أسفل الجدول | ملاحظة تصميم عن بيانات العينة، لا علاقة لها بالمستخدم |
| S-065 | أعمدة الرأس والصفوف غير متوازية (رأس بـ8 أعمدة متساوية بينما الصف بعمود إجراءات 210px) | منقولة حرفيًا كما في التصميم (قابلة للتعديل في الـpen) |
| S-065/066/067 | Sidebar مختصر (Admin Sidebar V3: 5 عناصر) بدل القائمة الكاملة | هكذا مرسومة؛ شاشات الموظفين تستخدم الغلاف القديم |
| S-007 / الجوانب | القائمة الجانبية تُرشَّح بالصلاحيات (الدور لا يرى ما لا يملك) | BR-084 / §16 (الواجهة حسب الدور) |
| S-007 | بطاقة «تنبيه عاجل» تظهر فقط عند وجود حالات | منطق: لا تنبيه بلا حالات |
| عام | سطر الدور في أسفل Sidebar يتغير حسب الدور الفعلي (مثلاً «حساب تشغيل») | التصميم يعرض دور Admin فقط |

| S-011-01 (xgLxv) | Sidebar مسطّح (15 عنصرًا بلا عناوين مجموعات) وbarإطار بـpadding/gap مختلف | الإطار مرسوم بنسخة شريط جانبي مغايرة لبقية خطوات المعالج (2–5: 248px بالمجموعات)؛ نستعمل الشريط القياسي لتفادي تبدّله بين الخطوات |
| S-011-02 | صفوف «خيارات المنتج» تُعرض لكل قيمة بسعر إضافي (مثل «تغليف لامع +0.40») وليس المختارة فقط | الـpen يعرض عينة مختارة فقط؛ بدون ذلك لا يمكن للمستخدم اختيار الخيار المتعدد |
| S-011-02 | حقل «الكمية» حقل إدخال بأيقونة السهم بدل قائمة منسدلة | الكمية حرة (MOQ فقط) |
| S-010 (قائمة الأوردرات) | لا يوجد frame في الـpen | مبنية على قالب «قائمة» + جدول «Orders — canonical V2» بنفس مقاسات S-022؛ تُستبدل عند رسم الـframe |
