## القرارات (حُسمت 2026-10-23 بتفويض المالك — قابلة للمراجعة)
| # | القرار | التنفيذ |
|---|---|---|
| D1 | التقريب: `HALF_UP` على كل بند ثم الإجمالي؛ الخصم يُحسب على المجموع الفرعي؛ كل المبالغ قروش صحيحة | `Money` + `PricingService` (مغطّى باختبارات) |
| D2 | الملفات: صور png/jpeg/webp وPDF؛ التصميم والمرجع 50MB، الشات 25MB، إثبات الدفع 10MB، الصوت webm/ogg/mp3/mp4/wav؛ النوع من المحتوى | `config/files.php` (تغيير الحد = تعديل القيمة ونشر) |
| D3 | واتساب: روابط `wa.me` يدوية يرسلها الموظف من هاتفه (بلا مزوّد API ولا قوالب ولا تكلفة)؛ يُراجَع عند زيادة الحجم | مُنفَّذ (زر «فتح واتساب» في إدارة الرابط) |
| D4 | مراجعة الطلب محجوزة لموظف واحد؛ لو غاب فإدارة (`order_requests.accept`) تفكّ الحجز فيعود «بانتظار المراجعة» ويُسجَّل في التدقيق | `ReviewOrderRequest::release` + زر «فكّ حجز المراجعة» + اختبار |
| D5 | الاحتفاظ: نسخ احتياطي يومي (`scripts/backup.sh`) يحتفظ بآخر 30 يومًا (`KEEP_DAYS`) مع نسخة خارج السيرفر؛ الملفات والـaudit تبقى دائمًا (audit للإضافة فقط)؛ مفاتيح Idempotency 7 أيام؛ صور البحث المؤقتة 30 دقيقة؛ اختبار استرجاع كل ربع سنة | جدولة `idempotency:prune` + سكربت النسخ |
| D6 | البحث بالصورة: بصمة إدراكية (dHash+aHash) للمطابق/القريب جدًا، دون فهم دلالي؛ PDF لا يُفهرس؛ الدلالي خارج النطاق الحالي | `ImageHasher` + اختبارات |
| D8 | الاستضافة: خادم Linux واحد (≥2 vCPU/4GB) بـ`docker-compose.prod.yml`، وTLS عبر وكيل عكسي (Caddy أو nginx+certbot) أمام الحاوية؛ الدومين من المالك؛ مجلدا MySQL والتخزين في volumes مع نسخ خارجي | `docs/13-deployment.md` |

### D7 — الفواتير (حُسم 2026-10-23)
فاتورة داخلية غير ضريبية. تظهر بوضوح على الواجهة وPDF أنها لا تمثل فاتورة ضريبية أو إثبات دفع. تُصدر بعد بدء الطباعة، تحفظ لقطة ثابتة للعميل والبنود والمبالغ والمدفوعات، ويمكن إلغاؤها بسبب مع تسجيل التدقيق ثم إصدار بديلة.
